Seal the cursor `ScopedStack.query()` returns. The adapter's cursor names the last record a page scanned, by ID and sort value, so a scoped query could hand any requester — anonymous included — the IDs, creation times and content-sort values of records it may not read, and a forged cursor could search those values. A scoped cursor is now AES-GCM sealed under `_config.cursorKey` and bound to the requester, filter and sort that produced it; only a cursor sealed for the same query resumes, and anything else is a 400. The key is written with `_config` (`Stack.open()` adds one to a store lacking it) and is immutable once set, so every `_config` version carries it. A scoped view that cannot read `_config` refuses to query with `RelayScopeError`. `_config` can no longer be shared, and a permission element on it reaches nobody. `MemoryAdapter` now stores the `_config` record the SQLite engines do. `generateCursorKey()` is exported from `@haverstack/core/adapter`.
